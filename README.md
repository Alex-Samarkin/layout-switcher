# layout-switcher

Утилита для переключения раскладки текста: конвертирует выделенный текст или содержимое буфера обмена между русской и английской раскладками (ЙЦУКЕН ↔ QWERTY).

## Возможности

- Читает выделенный текст (primary selection) или буфер обмена.
- Конвертирует текст в обе стороны (RU ↔ EN) с учётом регистра и знаков препинания.
- Пишет результат обратно в буфер обмена.
- Показывает всплывающее уведомление и короткий системный звук по завершении.
- Флаг `-buffer_only` — конвертировать только содержимое буфера обмена, не трогая выделение.

## Требования

- Linux, KDE Plasma на Wayland
- Klipper (менеджер буфера обмена, входит в Plasma)
- Зависимости (см. «Установка»)

## Установка (Wayland)

1. Установите зависимости (Manjaro/Arch):

   ```sh
   sudo pacman -S wl-clipboard libpulse libnotify sound-theme-freedesktop go
   ```

2. Соберите бинарник:

   ```sh
   go build -o layout_switcher .
   ```

3. Установите его в каталог из `PATH`:

   ```sh
   install -Dm755 layout_switcher ~/.local/bin/layout_switcher
   ```

4. Назначьте глобальный хоткей, чтобы запускать программу, не отрывая фокус от приложения (на Wayland программа читает выделение из primary selection и не должна красть фокус):

   - Системные настройки → Клавиатура → Горячие клавиши.
   - Добавить → Глобальное сочетание → Команда/URL.
   - В поле команды укажите `layout_switcher` (или полный путь `~/.local/bin/layout_switcher`).
   - Назначьте клавиши, например `Ctrl+Alt+L`.

   Для конвертации только буфера используйте команду `layout_switcher -buffer_only`.

## Использование

Выделите текст в любом приложении и нажмите назначенный хоткей (или запустите вручную):

```sh
./layout_switcher                 # конвертирует выделенный текст
./layout_switcher -buffer_only    # конвертирует только буфер обмена
```

Результат окажется в буфере обмена — вставьте его клавишей `Ctrl+V`.

> На Wayland выделение наружу отдают приложения с поддержкой primary selection (Qt/GTK). Некоторые Electron/Chromium-приложения могут не отдавать выделение — в этом случае используйте `-buffer_only` после копирования текста (`Ctrl+C`).
